# Easy Macros 1.0.0

- Initial release for Forever, Retail, and Classic Era.
- Drop a spell from the spellbook to build a character macro.
- Harmful spells get a combat starter macro (pet classes include /petattack).
- Helpful spells for others use mouseover; self-only spells use a plain cast.
- Tracks created macros, minimap button, and optional open-spellbook toggle.
