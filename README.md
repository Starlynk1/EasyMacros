# Easy Macros

Drop a spell from your spellbook to build a class-aware character macro.

Easy Macros builds the right macro for the spell you drop: combat starters for harmful spells, mouseover help for spells you can cast on others, and a simple cast for self-only buffs. It works on Retail, WoW Forever, and Classic (Era, Anniversary, Cataclysm, and MoP).

## Features

* Drop a spell from your spellbook onto the window, then click **Create**
* Harmful spells get a combat starter macro (clear / retarget / startattack / cast; `/petattack` for Hunter and Warlock)
* Helpful spells for others use a mouseover conditional
* Self-only helpful spells use a plain `/cast`
* Character-specific macros only (no duplicates)
* Drop a spell, click Create (macro attaches to your cursor), drop it on a bar
* Or drag again later from the created-macro list
* Same CreateMacro + PickupMacro path as Macro Spellbook / MacroActionBar (Forever)
* Minimap button
* Spellbook button that securely clicks Blizzard’s micro button (avoids Forever taint)

## Commands

| Command | Action |
| --- | --- |
| `/em` or `/easymacros` | Toggle the window |
| `/em show` / `/em hide` | Show or hide |
| `/em minimap` | Toggle the minimap button |

## Install

1. Download from CurseForge / WowUp, or clone this repository into `Interface/AddOns/EasyMacros`.
2. Enable **Easy Macros** in the addons list.
