# Easy Macros

Drop a spell from your spellbook to build a class-aware character macro.

Supports **WoW Forever**, **Retail**, and **Classic Era**.

## Usage

- `/em` or the minimap button opens the window.
- Drag a spell onto the preview area to create or update a character macro.
- Drag the macro icon to your action bars.
- `/em minimap` toggles the minimap button.

## Development

Work happens on the `develop` branch. Releases are tagged from `main` (for example `1.0.0`) and packaged by GitHub Actions for CurseForge.
